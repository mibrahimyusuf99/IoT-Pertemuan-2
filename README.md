Program ini dibuat menggunakan ESP32 untuk:

1. Membaca suhu dan kelembapan dari sensor DHT22
2. Mengirim data ke ThingSpeak secara berkala
3. Menghubungkan perangkat ke jaringan WiFi

Dengan Fitur:
1. Monitoring suhu dan kelembapan
2. Upload ke thinkspeak setiap 15 detik
3. Ketika suhu di atas 30 derajat, maka led akan menyala

Tools:
1. ESP 32
2. Sensor DHT22
3. LED
4. Resistor 220 ohm dan 1k ohm
5. kabel jumper
